# Parking Management System 🚗

## 📌 Description
Responsive frontend for a full-stack Parking Management System.  
Built with **React.js** and **Tailwind CSS** (JavaScript). Users can book parking slots and submit feedback.

## 🚀 Features
- View available parking slots
- Book parking slots
- Submit feedback
- Responsive UI for desktop and mobile

## 🛠 Tech Stack
- Frontend: React.js, Tailwind CSS, JavaScript  
- Backend: Node.js, Express.js, MongoDB, TypeScript  

## ⚙️ Installation
1. Clone repo: `git clone https://github.com/MuznaAli30/Parking-Frontend.git`  
2. Install dependencies: `npm install`  
3. Start dev server: `npm start`
